% Localization Method

% \begin{center}
% \textbf{\large State estimation}
% \end{center}

On each follower vehicle, the state $\mathbf{x}$ consists of the 2D positions and velocities of the follower and both leaders. 

Leaders take turn broadcasting their positions using time-synchronized messages, allowing all followers to simultaneously measure ranges from the leaders using OWTT ranging. These measured ranges along with reported leader positions are used to update the followers' state estimates.
